## To-Do List Web App

A simple and responsive To-Do List Web App developed as Task 5 of my Web Development Internship.

Objective

The objective of this project is to create a task management application that allows users to easily add, complete, and delete tasks while keeping the tasks saved after refreshing the webpage.

Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks
- Task counter
- Clear completed tasks
- Tasks remain saved after page refresh
- Responsive design for mobile and desktop

How It Works

1. Enter a task in the input field.
2. Click the Add button to add the task.
3. Mark the task as completed when it is finished.
4. Delete tasks that are no longer needed.
5. Tasks are automatically saved using localStorage.
6. Saved tasks are restored when the page is refreshed.

Learning Outcomes

Through this project, I learned how to:

- Create a responsive webpage using HTML and CSS.
- Use JavaScript for interactive functionality.
- Manipulate webpage elements using the DOM.
- Handle user events.
- Store and retrieve data using localStorage.
- Build and test a complete front-end web application.
